# งาน DXF → Revit: ปรับปรุงระบบปรับอากาศแผนกทันตกรรม รพ.ค่ายสุรนารี (แบบ R1)

สถานะ (2 ต.ค. 2026): ส่งชุดไฟล์รอบแรกแล้ว (Dental_Revit_package.zip) — สคริปต์ Dynamo **ยังไม่ได้ทดสอบใน Revit** รอผู้ใช้รันและแจ้งผล/ภาพหน้าจอ ยังไม่ทราบรุ่น Revit และความสูงจริงของอาคาร

## สิ่งที่อ่านได้จาก DXF (หน่วยเมตร, AC1032, แบบหลายแผ่นวางใน model space)
- แปลนออกแบบชั้น 1 อยู่ช่วง x −300…−250, ชั้น 2 x −236…−186 (ระยะเลื่อน 63.073 m); กริด A x=−292.505, กริด 4 y=−1.655 → ใช้เป็นจุด 0,0
- บล็อกสถาปัตย์: `sdfsdfd` (ชั้น 1), `erereer` (ชั้น 2)
- ระบบลม 13 ระบบ (บล็อกย่อยชื่อสุ่ม): OAU1-01/02/03, OAU2-01/02 (ลมจ่าย FA) และ EXH1-01…05, EXH2-01…03 (ลมระบาย EA); ท่อเขียนเป็นเส้นเดี่ยวบนเลเยอร์ plan, ขนาดเป็นข้อความนิ้วบนเลเยอร์ AC-DUCT-EA, สีเส้นบอกขนาด (6=16x10, 20=14x10, 3=10x10, 5=10x6; สี 2 = ท่อน้ำยา)
- หัวจ่าย CD14 26 ตัว, ช่องดูดลมระบาย 20 จุด, Air cleaner 600 CFM 17 ตัว (บล็อก A$C89f083f8), FCU 3 + CDU, OAU 5 + CDU 5, พัดลม EXH 8
- รวมท่อ: 106 ช่วง ≈ 207 m (10x6 103 m, 10x10 72 m, 14x10 21 m, 16x10 12 m)

## ข้อสังเกตจากแบบ (แจ้งผู้ใช้แล้ว)
- OAU 2-01: ป้าย 1000 CFM แต่ผลรวมหัวจ่าย 925; OAU 2-02: 1000 vs 880; EXH1-03: 1100 vs 990
- OAU 1-03: หัวจ่าย 3 ตัวไม่มีป้าย CFM (สมมติ 333 ต่อหัว)
- EXH1-01/02/04/05 ไม่มีป้ายขนาดท่อ (ประเมิน 10x10 ช่วงหลัก, 10x6 ช่วงแยก)

## ค่าที่สมมติ
พื้นถึงพื้น 3500, กึ่งกลางท่อ 2900, ฝ้า 2600 mm (ตัวแปรหัวสคริปต์)

## วิธีสร้างซ้ำ
ตัวอ่าน DXF เขียนเอง (ไม่มี ezdxf ในแซนด์บ็อกซ์): parse คู่ group code → เดินบล็อกซ้อน → ดึงเส้นท่อ/ป้าย → กราฟ → ระบบ → JSON → สคริปต์ Dynamo (Duct.Create + DirectShape กล่องแทนเครื่อง/หัวจ่าย, พยายามใส่ elbow/tee/transition) + DXF R12 (พื้นหลัง, 3DFACE)
