ติดตั้งบน Windows

  1. เปิดแอปที่ต้องการด้วย Microsoft Edge หรือ Google Chrome
  2. กดไอคอน “ติดตั้งแอป” ท้ายช่องที่อยู่เว็บ หรือเปิดเมนู ⋯ แล้วเลือก แอป › ติดตั้งแอปนี้
  3. แอปจะมีไอคอนบนเดสก์ท็อปและเมนู Start เปิดเป็นหน้าต่างของตัวเอง และใช้ได้แม้ไม่มีอินเทอร์เน็ต

ข้อมูลโครงการเก็บในเครื่องของคุณ ควรกด “สำรองข้อมูล” เป็นระยะ · เมื่อมีรุ่นใหม่ แอปจะอัปเดตเองตอนเปิดขณะต่ออินเทอร์เน็ต
